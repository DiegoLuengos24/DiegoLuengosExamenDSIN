# Gestor de Tareas MVC (Examen Tema 5)

## Propósito
Esta aplicación es un gestor de tareas sencillo diseñado para demostrar la implementación del patrón **Modelo-Vista-Controlador (MVC)** utilizando **PySide6**. Permite añadir tareas a una lista de forma dinámica y organizada.

## Estructura del Proyecto
- `model.py`: Gestión de datos y lógica de negocio.
- `view.py`: Interfaz gráfica de usuario con PySide6.
- `controller.py`: Conector entre la vista y el modelo.
- `main.py`: Punto de entrada de la aplicación.
